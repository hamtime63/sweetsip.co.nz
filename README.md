# SweetSip website

A responsive, static website for SweetSip, styled to match the supplied logo: warm cream, raspberry, pink and golden yellow.

## Preview
Keep the `index.html`, `styles.css`, `script.js` and `assets` folder together. Open `index.html` in a browser, or use VS Code with the Live Server extension for a more reliable local preview.

## Before publishing
- Replace the placeholder coffee prices (`$—`) with your real prices.
- Add your final location and opening hours.
- Confirm the contact email and add your social media links.
- The Google Fonts load from the internet; the site still has fallback fonts if they are unavailable.

## Publish
You can upload this folder to a GitHub repository and connect it to Cloudflare Pages. Use the project root as the build output directory; no build command is required.
