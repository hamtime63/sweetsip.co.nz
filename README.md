# SweetSip website

A static website for SweetSip, styled to warm cream, raspberry, pink and golden yellow colours.

## Preview
Keep the `index.html`, `styles.css`, `script.js` and `assets` folder together. Running on Cloudflare website.

## Before publishing
- The Google Fonts load from the internet; the site still has fallback fonts if they are unavailable.

## Publish
GitHub repository connected to Cloudflare Pages. Use the project root as the build output directory; no build command is required, update repository and it will auto publish.
